# ชุดทดลองเล่นระหว่างรอผู้เชี่ยวชาญ

สถานะเนื้อหายังเป็น demo/practice และรอ clinical sign-off

## สิ่งที่ทำต่อได้แล้ว

- ช่องผลข้างเคียง Case 1 เปลี่ยนเป็น `record-only` ต้องเลือกคำตอบเพื่อบันทึก แต่ไม่ตัดสินถูกผิดระหว่างรอเกณฑ์ที่ผู้เชี่ยวชาญยืนยัน
- การรับคำตอบนี้ไม่หมายความว่าตัวเลือกทั้งหมดถูกต้องทางคลินิก และไม่เปลี่ยน key ของยา ขนาด วิธีให้ หรือการติดตามเดิม
- ป้องกัน configuration ใส่ answer key กลับเข้า record-only โดยไม่เปลี่ยนสถานะของช่อง และตรวจว่าคำตอบที่บันทึกอยู่ในรายการตัวเลือกจริง
- ชุดตรวจผู้เชี่ยวชาญยังอยู่ที่ [clinical-review](clinical-review/README.md) และอัปเดต snapshot ให้ตรงกับรุ่นนี้แล้ว

## สร้างไฟล์ส่งทดลอง

เรียก `npm run trial:package` จาก repository บนเครื่องที่มี Node/npm และ `tar` ที่รองรับ ZIP คำสั่งจะตรวจชุด clinical review, unit/provenance tests, build และตรวจภาพในไฟล์ production ก่อนสร้าง ZIP พร้อม checksum ใน `tmp`

ZIP มีตัวเว็บ, `TRIAL_README.md` และ `trial-manifest.json` ที่ระบุ commit, สถานะ working tree, hashes และสถานะรอรับรอง ไม่มี source PSD/AI หรือภาพ prototype ที่แยกเก็บใน archive

แตกไฟล์แล้วให้บริการผ่าน HTTP server ที่รากโดเมน เช่น `python -m http.server 8080` แล้วเปิด `http://localhost:8080/` การเปิด HTML โดยตรงผ่าน `file://` หรือการวางใต้ subfolder ต้องจัดเส้นทางเพิ่มเติม

การทำ ZIP ไม่ใช่การ deploy เว็บไซต์สาธารณะ ทีมสามารถใช้ชุดนี้ทดลองก่อนเลือกโฮสต์ได้ ส่วนการรับรองยา เฉลย และ protocol ต้องรอผู้เชี่ยวชาญกรอกผลตรวจต่อไป
