# ชุดตรวจเนื้อหาคลินิก CardioSim

วันที่ตรวจเบื้องต้น: **3 พฤศจิกายน 2026** · สถานะ: **รอผู้เชี่ยวชาญตรวจและรับรอง**

ตรวจข้อมูลภายในเกมเทียบต้นทางในโครงการ และอ่านเอกสารอ้างอิงหลักเพื่อระบุประเด็นส่งตรวจ พบ **12 ประเด็น**, **2 เคส**, ข้อสอบก่อน/หลังเรียน **20 ข้อ** และใบความรู้ **6 หัวข้อ** ทุกช่องการรับรองยังว่าง

## เริ่มตรวจจากไฟล์ไหน

1. [findings.md](findings.md) — ประเด็นพร้อมตำแหน่งไฟล์/บรรทัดและคำถามที่ผู้ตรวจต้องตัดสิน
2. [questions.md](questions.md) — โจทย์ ตัวเลือก เฉลย และคำอธิบายเดิมครบ 20 ข้อ
3. [review-checklist.csv](review-checklist.csv) — แบบบันทึกผล 40 รายการ เปิดด้วย Excel ได้ มีช่องผู้ตรวจ คุณวุฒิ วันที่ มติ ข้อความ/เฉลยที่อนุมัติ และหลักฐาน
4. [content-snapshot.json](content-snapshot.json) — สำเนาข้อมูลเคส คำสั่งยา เฉลย และ source hashes ของเวอร์ชันที่ส่งตรวจ
5. [references.md](references.md) — แหล่งอ้างอิงและขอบเขตที่ใช้ประกอบการตรวจ
6. [knowledge-topics.md](knowledge-topics.md) — สรุปใบความรู้เดิมทั้ง 6 หัวข้อ

## ประเด็นที่ควรตรวจเป็นลำดับแรก

- **CLIN-01:** ฉลากผลิตภัณฑ์และความเข้มข้นก่อนรับรองเฉลยปริมาณยา 4 mL
- **CLIN-02:** ตัวเลือกผลข้างเคียงมีหลายข้อ แต่เครื่องตรวจรับ Hypotension เพียงข้อเดียว
- **CLIN-03–07:** สถานะทางเดินหายใจ O2, ECG/SVT และขอบเขตของ initial emergency response รวมเวลา/ค่าฟื้นตัวใน simulation
- **CLIN-09–12:** rubric การพยาบาล ข้อมูล Case 2, landmark ECG และคุณภาพข้อสอบ

## วิธีส่งผลตรวจกลับให้ทีมพัฒนา

ใน CSV ให้ระบุ `decision` เป็น `approve`, `revise` หรือ `insufficient-evidence` พร้อมผู้ตรวจ/คุณวุฒิ/วันที่ และใส่ข้อความหรือ key ที่อนุมัติจริงใน `approved_wording_or_key` แยกตามรายการ หากหลักฐานไม่พอให้ระบุเอกสารที่ต้องการเพิ่ม ช่อง `status` เริ่มเป็น `pending` ทั้งหมด

หลังแก้ตามมติ ต้องตรวจความสอดคล้องของเคส ใบออเดอร์ UI, เฉลย และการให้คะแนนซ้ำ และออกรุ่นข้อมูลให้ผู้ตรวจรับรองอีกครั้ง สถานะ clinical approval ในชุดนี้ไม่ได้เปลี่ยนตามผลทดสอบซอฟต์แวร์

ขณะนี้เกมยังใช้ข้อมูล demo เดิม การให้คะแนน Case 1 เป็นคะแนนเดโม ส่วน Case 2 ยังเป็นรอบฝึกไม่ให้คะแนนทางคลินิก

## ตรวจว่าชุดเอกสารตรงกับโค้ด

- สร้างใหม่: `npm run clinical:review:export`
- ตรวจ source hashes และความครบ: `npm run clinical:review:check`

คำสั่ง export จะปฏิเสธการเขียนทับ CSV ที่มีการแก้ไข ให้เก็บสำเนาผลตรวจแยกตามรุ่นและย้าย CSV ที่กรอกแล้วออกก่อนสร้างชุดใหม่ ช่องรับรองของชุดใหม่เริ่มว่าง ผลตรวจ hashes เป็นการตรวจรุ่นข้อมูล ไม่ใช่การรับรองทางการแพทย์
