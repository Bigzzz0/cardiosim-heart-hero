# CardioSim UX playtest

Use this guide with five people who have not seen the demo. Run the session on the device they would normally use. Do not explain the controls or point out where to click; read only the task prompts below. This is a UI usability check, not a clinical knowledge test.

## Read to each participant

“Please play this short patient-care simulation. Think aloud when something is unclear. You can stop at any time. The values and treatment content are demo material and are not clinical guidance.”

## Tasks

1. Start the case and find out what the patient needs.
2. Assess the patient using the room tools. If the first drop seems wrong, use the feedback to recover.
3. Complete the diagnosis and nursing-care boards. Confirm your choices and correct them if needed.
4. Respond when the patient deteriorates. Complete ABC in order and open the Patient Chart to review findings.
5. Place all six ECG leads and confirm. Review the mission result and find how to play again.

## Record for each participant

| Measure | Record |
|---|---|
| Device and viewport | Desktop mouse, touch device, or keyboard; screen size |
| Completion | Finished without help / finished with help / stopped |
| Hesitations | Step and what the participant expected to happen |
| Misunderstood controls | What they tried and what they thought would happen |
| Recovery | Whether feedback helped them retry without help |
| Clarity rating | 1–5 for goal, tool use, feedback, and result screen |
| Comment | The most confusing and most helpful moment |

Do not coach during the tasks. If a participant asks for help, note the exact question, then give the smallest hint needed to continue. Treat the same blocker or confusion from two or more participants as a required fix before calling the UX polished.
