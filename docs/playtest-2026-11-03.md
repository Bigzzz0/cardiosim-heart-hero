# ทดลองเล่นและตรวจการใช้งาน · 3 พฤศจิกายน 2026

ทดสอบผ่านเบราว์เซอร์ Edge แบบอัตโนมัติและตรวจภาพหน้าจอ ครอบคลุมคอมและหน้าจอมือถือจำลอง รวมถึงการส่ง touch gesture จริงผ่านเบราว์เซอร์ การทดสอบนี้ยังไม่ใช่ผลประเมินจากผู้เล่นจริงหรือการรับรองเนื้อหาคลินิก

## จุดที่พบและแก้

- หน้าเตรียมยา: แถบปรับปริมาณสั้นและตัวเลขอยู่ชิดปุ่มลากบนมือถือ ขยายให้ใช้ความกว้างที่มี แยกสเกลจากปุ่มลาก และคำนวณระยะลากจากขนาดแถบจริง
- หลังยืนยันปริมาณผิดแล้วแก้ค่า: ข้อความผิดเดิมค้างอยู่ ปรับให้แสดงสถานะรอยืนยันใหม่เมื่อแก้ปริมาณ โดยไม่ให้คะแนนหรือบอกว่าถูกก่อนกดยืนยัน

ภาพ syringe ยังคงเป็นภาพจากเวชนิทัศน์ ไม่เปลี่ยนภาพหรือเพิ่มภาพ AI

## การตรวจ

- แถบปริมาณยา: 1440×900, 1280×720, 1024×768 และ 390×844; ลากด้วยเมาส์/สัมผัส ใช้คีย์บอร์ด ยกเลิกสัมผัส และยืนยัน/ลองใหม่
- เกมเต็มเส้นทาง Case 1 และ Case 2: ประเมินผู้ป่วย จัดวางคำตอบ เตรียมยา I/O, Emergency, ABC, ECG, ผลลัพธ์ และส่งข้อมูลกลับ Post-test
- ตรวจชนิดภาพและที่มาของภาพที่เผยแพร่ผ่านรายการ source/hash และ unit tests

คำสั่งตรวจ: `npm run test:game:workbench`, `npm run test:game:browser`, `npm run test:game`, `npm run build` (ตั้ง `CARDIOSIM_BROWSER_CHANNEL=msedge` สำหรับ browser checks)

## งานที่ยังต้องให้ทีมส่งหรือตรวจ

- ผู้เชี่ยวชาญรับรองค่าของ Case 1, คำสั่งยา, การตีความ ECG และเฉลย
- Case 2: ค่าสัญญาณชีพ Doctor Order, ECG strip และเฉลยยังไม่มีในเรื่องย่อ จึงคงโหมดฝึกไม่ตัดสินทางคลินิก
- ภาพคนไข้เฉพาะ Case 1: ปัจจุบันใช้ภาพแยกเลเยอร์ที่ได้รับร่วมกันทั้งสองเคส
- Template ใบความรู้ 05, วิดีโอจริง และภาพอุปกรณ์ที่ยังไม่มี เช่น BP, SpO₂ และแอมพูล
- ให้ผู้เล่นจริงลองงานรอบนี้และส่งข้อสังเกตก่อนเปิดเว็บสาธารณะ
